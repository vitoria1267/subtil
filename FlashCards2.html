O que é

CSS?

Cascading Style Sheets

É uma linguagem de estilo utilizada para definir a apresentação (design, cores, fontes) de um documento escrito em HTML.

O que é 

HTML?

Hypertext Markup Language

É uma linguagem de marcação utilizada para estruturar os elementos da página, como títulos, parágrafos, tabelas, imagens, vídeos, links.

O que é

JavaScript?

Java Script

É uma linguagem programação utilizada para dar movimento, realizar atualização dos elementos dinamicamente e lidar com dados enviados e recebidos pela página.
